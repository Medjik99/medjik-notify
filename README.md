MEDJIK Notify is a free, modern and standalone notification system built for FiveM servers.

Designed with a clean and premium interface, MEDJIK Notify provides developers with a simple way to display notifications while remaining completely framework-independent.

Whether you're building a standalone resource or working with ESX, QBCore, Qbox or another framework, MEDJIK Notify can be easily integrated into your scripts.

MEDJIK Notify is designed specifically for real FiveM usage rather than being just another UI component.

Notifications are managed through a queue system to keep the interface clean even when multiple resources send notifications at the same time.

Persistent notification IDs allow resources to create, update and remove notifications dynamically, making the system suitable for more than simple alerts.

⚡ Developer Friendly

MEDJIK Notify is built to be easy to integrate into other FiveM resources.

Use it for anything from simple success/error messages to persistent status notifications and interactive actions.

The system provides both client-side and server-side integration options, allowing it to fit cleanly into different resource architectures.
